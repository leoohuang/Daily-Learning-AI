### 📚 语音和声学分析核心公式总结

#### 一、频率与音高关系（半音 ST）

| 名称 | 公式 | 变量含义 | 关键常数/关系 |
| :--- | :--- | :--- | :--- |
| **频率与半音** | $$f_{\text{新}} = f_{\text{原}} \cdot 2^{\Delta ST / 12}$$ | $\Delta ST$：半音变化数 (向上为正，向下为负) | **1 个八度 ($\text{Octave}$) = 12 ST** |
| | | $f_{\text{原}}, f_{\text{新}}$：频率 (Hz) | **6 个半音 (Tritione) = $\sqrt{2}$** |

* **应用场景：** 计算 $100 \text{ Hz}$ 向下 $6$ 个半音的频率：
  $$f_{\text{新}} = 100 \cdot 2^{-6/12} = \frac{100}{\sqrt{2}} \approx 71 \text{ Hz}$$

#### 二、声强级 (SIL) 与声强 (I)

| 名称 | 公式 | 变量含义 | 关键常数/关系 |
| :--- | :--- | :--- | :--- |
| **声强级 ($\text{dB}$) 定义** | $$L_I = 10 \cdot \log_{10}\left(\frac{I}{I_0}\right) \text{ dB}$$ | $L_I$：声强级 ($\text{dB}$) | **$I_0$ (参考声强) $= 10^{-12} \text{ W/m}^2$** |
| **声强反推公式** | $$I = I_0 \cdot 10^{L_I / 10}$$ | $I$：声强 ($\text{W/m}^2$) | $\boldsymbol{10 \text{ dB}}$ $\implies$ 强度 $10$ 倍 |

* **应用场景：** 计算 $80 \text{ dB}$ 对应的声强 $I$：
  $$I = 10^{-12} \cdot 10^{80 / 10} = 10^{-4} \text{ W/m}^2$$

#### 三、DFT/FFT 频率分辨率

| 名称 | 公式 | 变量含义 | 关键意义 |
| :--- | :--- | :--- | :--- |
| **频率分辨率** | $$\Delta f = \frac{f_s}{N}$$ | $\Delta f$：频率间隔/分辨率 ($\text{Hz}$) | **$N$ 越大**，$\Delta f$ 越小，**分辨率越高**。 |
| | | $f_s$：采样率 ($\text{Hz}$) | |
| | | $N$：DFT/FFT 点数（分析帧大小） | |

* **帧长 $T$ 的关系：** $$\Delta f = \frac{1}{T}$$
  （$T$ 越长，分辨率越高。）

#### 四、语音周期数计算

| 名称 | 公式 | 变量含义 | 物理意义 |
| :--- | :--- | :--- | :--- |
| **周期总数** | $$N = f_0 \times T$$ | $N$：周期总数（无单位） | $f_0$ (周期/秒) $\times T$ (秒) = 周期总数 |
| | | $f_0$：基频 ($\text{Hz}$) (周期/秒) | |
| | | $T$：持续时间 (秒) | |

* **应用场景：** $f_0 = 150 \text{ Hz}$，持续 $1.2 \text{ s}$ 的周期数：
  $$N = 150 \text{ Hz} \times 1.2 \text{ s} = 180 \text{ 个周期}$$
