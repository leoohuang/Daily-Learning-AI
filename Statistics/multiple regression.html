Part 1

简单回归回顾

我们先从单预测变量模型开始。这里我们生成了一组数据 d1，其中 $y$ 是 $x$ 的函数加上一些噪声。

R Console
library('tidyverse') d1 <- tibble(x = runif(50, -5, 5), y = 5 + -9 * x + rnorm(50, 0, 1)) model1 <- lm(y ~ x, data = d1) summary(model1)

观察点： 截距 (Intercept) 应接近 5，斜率 (x) 应接近 -9。$R^2$ 非常高，因为噪声很小。

Part 2

引入第二个变量

生活很少如此简单。通常 $y$ 取决于多个变量。这里我们引入 $x_1$ 和 $x_2$。 如果我们只看 $y \sim x_1$ 或 $y \sim x_2$，我们可能会得到误导性的图像（即 omitted variable bias，虽然在此例中设定为独立，影响较小）。

正确的做法是将所有预测变量放入同一个模型中：

R Console
d2 <- tibble( x1 = runif(20, 13, 27), x2 = runif(20, -3, 11), y = -26 - 6 * x1 + 7 * x2 + rnorm(20) ) # Multiple Regression m3 <- lm(y ~ x1 + x2, data = d2) summary(m3)

系数解读

  • Intercept: 当 $x_1=0, x_2=0$ 时的 $y$ 值。
  • x1: 当 $x_2$ 保持不变时，$x_1$ 增加 1 单位带来的 $y$ 变化。
  • x2: 当 $x_1$ 保持不变时，$x_2$ 增加 1 单位带来的 $y$ 变化。
Part 3: Exercise

实战：阅读反应时

我们使用 beginningReaders 数据集。首先汇总每个单词的频率 (Freq)、长度 (OrthLength) 和平均反应时 (RT)。

任务： 比较仅使用频率的模型与同时使用频率和长度的模型。

R Console
# Model 1: RT ~ Freq m_freq <- lm(RT ~ Freq, data = words) # Model 2: RT ~ Freq + OrthLength m_both <- lm(RT ~ Freq + OrthLength, data = words) cat("R2 (Freq only):", summary(m_freq)$r.squared, "\n") cat("R2 (Both): ", summary(m_both)$r.squared)

通常，增加单词长度（OrthLength）会提高 $R^2$，因为长单词往往读起来更慢，这是频率之外的额外信息。

Part 4

非标准化系数的陷阱

如果 $x_1$ 的范围是 0-1，$x_2$ 的范围是 0-1000，它们的系数大小会相差巨大，但这不代表重要性。

解决方案： 标准化 (z-score)。将所有预测变量转换为标准差单位。

x_z = (x - mean(x)) / sd(x)
R Console
d2 <- d2 %>% mutate(x1_z = scale(x1), x2_z = scale(x2)) m_std <- lm(y ~ x1_z + x2_z, data = d2) summary(m_std)

注意：标准化后，$R^2$ 和 $p$ 值保持不变，但系数 (Estimates) 现在可以直接比较大小了。

Part 5

模型诊断

模型拟合好并不代表它是对的。我们需要检查假设：

  • 1. 残差正态性 (Normality) 残差分布应呈钟形曲线。通过直方图或 Q-Q 图检查。
  • 2. 同方差性 (Homoscedasticity) 残差的离散程度不应随预测值变化。Residuals vs Fitted 图中不应出现喇叭口形状。

右侧展示了交互式的诊断图。尝试生成不同噪声的数据来观察图形变化。

Part 6

独立性假设

线性回归假设所有数据点都是独立的。但在 beginningReaders 中，每个受试者 (Subject) 贡献了多个数据点。

R Console
table(beginningReaders$Subject)
S10 S12 S13 S14 ... 160 153 174 118 ...

后果： 模型会对自己太“自信”（低估标准误）。
解法： 使用混合效应模型 (Mixed-effects models)，这将在后续课程（第14-15章）中讲解。

Part 7: Advanced

共线性的诅咒

当预测变量之间高度相关（例如 $x_1$ 和 $x_2$ 的 correlation = 0.95）时，模型很难区分它们各自的贡献。

表现

1. 系数估计值变得不稳定（方差膨胀）。
2. 单独看 $x_1$ 显著，单独看 $x_2$ 显著，放一起都不显著，或者系数符号反转。

在右侧实验室中，尝试增加相关系数 $\rho$，观察 $x_1$ 和 $x_2$ 的估计系数如何变得疯狂跳动。

Part 8

校正 $R^2$

这就引出了一个问题：我们是不是应该无脑加变量？

事实： 只要增加变量（哪怕是完全随机的噪声），$R^2$ 永远会上升（或不变），绝不会下降。

解法： 使用 Adjusted $R^2$。它引入了惩罚项，如果新变量没有解释足够多的方差，Adjusted $R^2$ 会下降。

R Console
d2 <- d2 %>% mutate(x_random = rnorm(nrow(d2))) m_noise <- lm(y ~ x1 + x2 + x_random, data = d2) summary(m_noise)$r.squared # 略微上升 summary(m_noise)$adj.r.squared # 可能下降
