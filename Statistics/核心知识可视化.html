Chapter 01

数据的“证件照”

在处理复杂数据前，我们需要先看清它的长相。描述性统计是数据的快照，核心有两个参数：

均值 (Mean, $\mu$)

数据的重心。移动右侧的 Mean滑块，你会看到整座“山峰”在水平移动。

标准差 (SD, $\sigma$)

数据的胖瘦。标准差越小，山峰越陡峭（数据越集中）。 

data <- c(15, 20, 25, 30, 35)
mean(data)  # 25
sd(data)    # 7.9
Chapter 02

推断的艺术

我们只能看到样本，却想推测上帝视角的“总体”。这就是推断统计的任务。

P 值的直觉

如果两个组真的没有区别（零假设 $H_0$ 为真），那么我观察到这么大差异的概率是多少？
当 P 值很小（通常 < 0.05）时，我们认为这不太可能是巧合，从而拒绝零假设。

右侧展示了一个 T 分布。试着拖动 T值滑块。当你进入红色的“拒绝域”时，P 值会变得显著。 

# 独立样本 t 检验
t.test(group_A, group_B)
# P < 0.05 -> 显著差异
Chapter 03

寻找规律的直线

线性回归试图画一条线，让它离所有数据点“最近”。这条线由两个灵魂决定：

  • 截距 ($b_0$) 起步价。当 $x=0$ 时，$y$ 的数值。
  • 斜率 ($b_1$) 单价。$x$ 每增加 1，$y$ 增加多少。
$$ y = \color{blue}{b_0} + \color{red}{b_1}x + \epsilon $$
Chapter 04

控制变量的力量

现实世界很少是单一因素决定的。多元回归允许我们同时考虑多个变量 ($x_1, x_2...$)。

交互作用 (Interaction)

有时候，$x_1$ 的效果取决于 $x_2$。比如：咖啡($x_1$) 提神的效果，取决于你是否 缺觉($x_2$)。

右侧是一个简单的预测计算器。试着调整两个变量，看看预测结果如何变化。 

# 多元回归 + 交互作用
lm(score ~ hours * sleep, data = df)
# 等同于: hours + sleep + hours:sleep
Chapter 05

驯服不听话的数据

真实数据往往不符合正态分布（比如反应时、工资，都是右偏的）。这时我们需要“魔法”。

Log 变换 (对数)

专治“长尾巴”。它能把拉长的右尾缩回来，让分布变对称。

观察右侧图表，点击 Log 按钮，看偏态分布如何瞬间变回正态。 

# 原始模型不佳
lm(rt ~ age, data)

# 变换后效果更好
lm(log(rt) ~ age, data)
Chapter 06

从文字到数学

回归方程只吃数字。怎么把 "Group A/B/C" 喂给它？答案是虚拟编码与基准变换。

  • 截距 永远等于 基准组 的均值。
  • 斜率 永远等于 比较组与基准组 的差值。

在右侧实验室中，尝试切换基准组。你会发现数据点没动，但描述它们的数学方程完全变了。 

# 切换基准为 B
df$group <- relevel(df$group, ref = "B")
lm(value ~ group, data = df)
