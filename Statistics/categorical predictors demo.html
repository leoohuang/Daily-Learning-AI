分类预测变量 (Categorical Predictors)

基于 Marcin Włodarczak 的课程讲义 - 交互式学习指南

1. 为什么要学这个？

在传统的线性回归中，我们习惯用数字预测数字（例如：用身高预测体重）。但当我们想要比较不同的类别（例如：实验组 vs 对照组）时，该怎么办？

核心挑战： 计算机只懂数字，不懂 "Group A" 或 "Group B"。我们需要一种翻译机制。

2. 只有两个组：虚拟编码 (Dummy Coding)

我们将类别转换为开关信号：
Group A = 0 (基准), Group B = 1 (比较组)。

回归方程：

$$y = 4.6 - 5.7x$$

  • 截距 (4.6): 当 x=0 (Group A) 时的预测值，即 A 的均值。
  • 斜率 (-5.7): 当 x 从 0 变 1 时 y 的变化量，即 B 与 A 的均值差。
尝试计算： 如果我是 Group B (x=1)，我的值是多少？

答案：4.6 + (-5.7) × 1 = -1.1 (正是 B 的均值)

4. 统计假设 (Assumptions)

  • 方差齐性 (Constant Variance): 所有组的数据分布宽度（波动）应该差不多。
  • 正态性 (Normality): 模型的预测误差（残差）应该符合正态分布。
  • 独立性 (Independence): 数据点之间互不影响。

5. 极简复习小抄

  • 1 截距 (Intercept) = 基准组的平均值。
  • 2 斜率 (Slope) = 该组与基准组的“均值差”。
  • 3 多组比较 = 哪怕有100个组，也永远是“1个基准 + 99个相对于基准的差异”。
