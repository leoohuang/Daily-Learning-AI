# 吴恩达机器学习笔记：多元线性回归

这一章的核心是将简单的“单变量回归”扩展到“多变量”，并学习如何让梯度下降算法在复杂数据上跑得更快、更稳。

---

## 1. 模型表示 (Model Representation)

从预测只看一个特征（如：面积），变成了看多个特征（如：面积、卧室数、层数、房龄）。

* **假设函数 (Hypothesis):**
    $$h_\theta(x) = \theta_0 + \theta_1 x_1 + \theta_2 x_2 + \dots + \theta_n x_n$$
* **向量化形式 (Vectorization):**
    为了方便计算机一次性计算，我们引入 $x_0 = 1$，将公式简化为两个矩阵（向量）相乘：
    $$h_\theta(x) = \theta^T x$$
    * $\theta$: 参数矩阵 (权重)
    * $x$: 特征矩阵 (输入数据)

---

## 2. 梯度下降 (Gradient Descent)

这是求解参数 $\theta$ 的核心算法。想象成**“蒙眼下山”**的过程。

### **核心公式**
$$\theta_j := \theta_j - \alpha \frac{1}{m} \sum_{i=1}^{m} (h_\theta(x^{(i)}) - y^{(i)}) x_j^{(i)}$$

### **公式直觉翻译**
* **$\theta_{new} = \theta_{old} - \text{修正量}$**: 用当前的位置，减去我们要移动的步伐（因为是下山，所以用减号）。
* **$\sum$ (求和符号)**: **“综合大家的意见”**。把所有样本数据的误差加起来，看看到底整体偏向哪里。
* **$\frac{1}{m}$ (平均)**: 对总误差取平均值。
* **$(h - y)$**: **“方向感”**。预测值比真实值大了还是小了？决定了往哪个方向走。
* **$\alpha$ (学习率)**: **“步长”**。这一步迈多大？

---

## 3. 两个关键的工程技巧 (Practical Tricks)

这是这一章最实用的部分，如果不做这两步，梯度下降可能会非常慢或者不收敛。

### **A. 特征缩放 (Feature Scaling)**
* **问题**: 如果特征范围差距巨大（例如：房价 $0-2000$，卧室数 $1-5$），代价函数的图像会变成**细长的椭圆**。算法会在峡谷壁之间来回震荡，收敛极慢。
* **解决**: 把所有特征缩放到大致相同的范围，例如 $[-1, 1]$。
* **效果**: 图像变成**正圆形**，算法可以直接向圆心（最低点）走直线，速度飞快。
* **常用方法**: 均值归一化 (Mean Normalization)。
    $$x_i := \frac{x_i - \mu_i}{s_i}$$ (减去平均值，除以范围/标准差)

### **B. 学习率 $\alpha$ 的调试 (Learning Rate)**
如何判断梯度下降是否正常工作？画出 **$J(\theta)$ (代价) 随 迭代次数** 变化的曲线图。

* **正常**: 曲线随着迭代一直在下降。
* **$\alpha$ 太小**: 曲线下降，但非常缓慢（像蚂蚁搬家）。
* **$\alpha$ 太大**: 曲线反而上升，或者忽上忽下（一步跨过了山谷，无法收敛）。
* **策略**: 尝试不同的 $\alpha$ 值（例如：0.001, 0.003, 0.01, 0.03, 0.1...），选那个下降最快且稳定的。

---

## 4. 另一种解法：正规方程 (Normal Equation)

除了梯度下降，还有一种“一步到位”解出 $\theta$ 的数学方法。

* **公式**: $\theta = (X^T X)^{-1} X^T y$
* **对比**:
    | 梯度下降 (Gradient Descent) | 正规方程 (Normal Equation) |
    | :--- | :--- |
    | 需要选择 $\alpha$ | 不需要 $\alpha$ |
    | 需要多次迭代 | 一次运算得出结果 |
    | **适合特征量 $n$ 很大 (如 $n > 10000$)** | **特征量 $n$ 很大时运算极慢 (矩阵逆运算耗时)** |
    | 现代深度学习主要用这个 | 仅在简单线性回归中小规模数据使用 |
