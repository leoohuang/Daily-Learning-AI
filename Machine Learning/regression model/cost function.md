如果我们有一些数据，例如，房价数据；我们可以通过$f_{w,b}(x) = wx + b$ 来拟合这些数据，以便预测未来的房价。

## 核心问题

我们怎么知道这条线画得好不好？这就需要一个评判标准，也就是 代价函数（Cost Function）。

**代价越小，误差越小，模型越准**

## 核心公式
$$J(w,b) = \frac{1}{2m} \sum\limits_{i = 0}^{m-1} (f_{w,b}(x^{(i)}) - y^{(i)})^2$$

1.找差距：$(f_{w,b}(x^{(i)}) - y^{(i)})$ —— 算出“预测价格”和“真实价格”差了多少。

2.平方：$(...)^2$ —— 把差值平方。这样无论是估高了还是估低了，结果都是正数（而且误差越大，惩罚越重）。

3.求平均：$\frac{1}{2m} \sum$ —— 把所有房子的误差加起来，算一个平均值（除以 $2m$ 是为了后续求导方便，数学技巧）。


## 3. 代码实现：把公式翻译成 Python
文档中的 `compute_cost` 函数是必须要看懂的，它是上述公式的直接翻译：

```python
def compute_cost(x, y, w, b):
    m = x.shape[0]             # 样本数量
    cost_sum = 0
    for i in range(m):         # 遍历每一个样本
        f_wb = w * x[i] + b    # 1. 算出预测值
        cost = (f_wb - y[i]) ** 2  # 2. 算出平方误差
        cost_sum = cost_sum + cost # 3. 累加误差
    total_cost = (1 / (2 * m)) * cost_sum # 4. 算平均
    return total_cost
