# 线性回归梯度下降（吴恩达课程-直观简单版）

## 1. 我们想干嘛？
不管是 $\theta_0$ 还是 $\theta_1$，我们的目的只有一个：
**找到一条直线，让它离所有的红叉叉（数据点）最近。**

## 2. 什么是“梯度下降”？
想象你在一个**碗**的边缘（这个碗就是**代价函数**，代表误差）：
* **碗底**：误差最小的地方（我们要去的地方）。
* **你在的位置**：当前的 $\theta$ 值，误差很大。

**梯度下降就是“下山”的过程：**
1.  **看看脚下**：坡度往哪里倾斜？（算导数/斜率）
2.  **迈出一步**：往低处走一步。（更新参数）
3.  **重复**：一步步走，直到走到碗底不动了。

## 3. 它是怎么调整直线的？
每一次“下山”迈一步，直线就会变一下：
* **$\theta_0$ (截距)**：负责把直线 **上下平移**。
* **$\theta_1$ (斜率)**：负责把直线 **旋转角度**。

**梯度下降就是不断地平移和旋转这条线，直到它卡在数据中间，位置最完美。**

## 4. 那个公式是什么意思？

吴恩达课里的公式看起来很长，其实翻译成中文非常简单：

$$
\text{新值} = \text{旧值} - \text{步长} \times \text{坡度}
$$

对应到数学符号：

$$
\theta_j := \theta_j - \alpha \frac{\partial}{\partial \theta_j} J(\theta)
$$

* **$\theta_j$ (旧值)**：你现在在哪。
* **$-$ (减号)**：因为我们要**逆着**坡度走（下山），所以是减。
* **$\alpha$ (步长)**：**学习率**。
    * 设得太大：步子太大，直接跨过碗底摔对面去了。
    * 设得太小：像蚂蚁一样挪，半天走不到底。
* **后面那坨分数 (坡度)**：**导数**。
    * 它告诉你现在的坡有多陡，以及该往哪个方向走。

## 5. 两个参数稍微有点区别

因为直线方程是 $y = \theta_0 + \theta_1 x$。

* **更新 $\theta_0$ 时**：公式后面只有误差。
* **更新 $\theta_1$ 时**：公式后面要**多乘一个 $x$**。
    * *简单记法：因为 $\theta_1$ 是跟在 $x$ 旁边的，所以更新它的时候也要带上 $x$。*

---

**总结成一句话：**
梯度下降就是**盯着误差（碗底）**，一步步**调整（$\alpha$）** 直线的**高度（$\theta_0$）** 和 **角度（$\theta_1$）**，直到误差最小。

# 为什么有 lm() 还要学梯度下降？

## 1. 对比表格

| 特性 | lm() / 正规方程 (Normal Equation) | 梯度下降 (Gradient Descent) |
| :--- | :--- | :--- |
| **原理** | 数学公式直接解方程 (解析解) | 一步步迭代逼近 (数值解) |
| **计算速度** | 小数据时极快 | 任何时候都比较平均 |
| **大数据能力** | **差**。特征超过 1 万时非常慢 | **强**。适合百万级数据 |
| **学习率 $\alpha$** | 不需要，全是自动的 | 需要手动调参 |
| **适用范围** | **仅限**线性回归等简单模型 | **万能**。适用于逻辑回归、神经网络等 |

## 2. 结论
* **如果你在做统计分析**（数据量几千几万行，只是做个简单的回归）：**请直接用 R 的 `lm()`**，不要用梯度下降，那样是自找麻烦。
* **如果你在学机器学习/深度学习**：吴恩达教你梯度下降，不是为了让你解线性回归，而是为了**让你习惯“通过迭代优化误差”这种思维方式**，因为这是所有现代 AI（包括 ChatGPT）的基石。
